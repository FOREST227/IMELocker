# 输入法锁定 v0.0.5

## 修复

- 修正图标导出时透明背景被填充为白色的问题，旧版 macOS 使用的 ICNS 现已自带圆角和透明边缘。
- README 图标与应用图标同步更新。

## 优化

- 去掉多余描边、减淡阴影，统一键盘与锁的蓝色配色。
- 放大锁的轮廓，增强“输入法锁定”的识别度。
- 为 16px、32px 提供简化图案，减少键帽、加粗锁柄并去除锁孔和投影。
- 新增图标透明度、ICNS 变体完整性及 README 图标一致性检查。

## 下载与兼容性

- 推荐下载 `universal` 安装包，同时支持 Apple Silicon 和 Intel Mac。
- 另提供 `arm64` 和 `x86_64` 安装包。
- 最低系统要求保持 macOS 12；登录启动功能需要 macOS 13 或更高版本。
- 安装前请先退出旧版应用，再将新版拖入“应用程序”替换。
- 安装包使用本地 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
