# 输入法锁定 v0.0.8

## 核心修复：告别输入被打断与“显示中文却打英文”

- **修复切回微信输入法后仍打出英文**：切换中文/第三方输入法时，优先通过前台焦点进程的 Text Services Manager 端口发送切换请求（与 macOS 原生输入法菜单同路径，零额外权限，失败自动回退 `TISSelectInputSource`），规避跨进程 `TISSelectInputSource` 导致的输入法控制器瞬时失活问题。
- **打字与交互期间严格拒绝打断**：基于免权限的键盘/鼠标活跃检测，只要你正在连续打字（含 `keyDown` / `keyUp` / `flagsChanged`）、按住修饰键（`Command` / `Control` / `Option` / `Shift`）或按下鼠标键（划词、拖动、点选候选词），自动切换将严格顺延，绝不在输入中途强行打断，等停手后再静默恢复。
- **切后冷却与抖动过滤**：默认防抖调整为 `80ms` 以忽略弹窗引起的短暂输入源闪跳，单次切换后设置 `300ms` 冷却期避免连续重切干扰输入法激活。
- **父容器与子模式 ID 精确匹配**：列表自动过滤冗余的 `ModeEnabled` 父容器（如 `com.tencent.inputmethod.wetype`），保留具体输入模式（如 `com.tencent.inputmethod.wetype.pinyin`）；已保存旧父容器 ID 会自动升级并等价识别，杜绝反复重切。

## 全新应用图标

- 全新设计的 macOS 风格图标：**立体珍珠白「中」字键帽 + 钴蓝锁扣**，具备透明圆角安全边距与柔和阴影，深浅色桌面与 Dock 均清晰立体，同步封装全套 11 种分辨率 ICNS 变体。

## 构建稳定性

- 打包脚本 `scripts/build_dmg.sh` 新增 `hdiutil` 重试保护，避免 macOS 偶发磁盘镜像资源锁冲突导致打包失败。

## 下载与兼容性

- 推荐下载 `universal`，同时支持 Apple Silicon 和 Intel Mac；另提供 `arm64` 和 `x86_64`。
- 发布页同步附带 `SHA256SUMS.txt`，可用于校验 `.dmg` 文件完整性。
- 最低系统要求保持 macOS 12；登录启动功能需要 macOS 13 或更高版本。
- 安装前请退出旧版，再将新版拖入“应用程序”替换。
- 安装包使用本地 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
