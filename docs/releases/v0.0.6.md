# 输入法锁定 v0.0.6

## 菜单优化

- 顶部状态改为独立信息区，提高可读性，避免重要文字显示为禁用灰色。
- 输入法分组标题简化为“输入法”；根据当前状态提示如何锁定或解锁。
- 输入法和登录启动统一使用圆形状态标记，移除重复勾选图标。
- “开机自启”改为“登录时启动”，直接显示待批准或系统不支持等状态。
- 长输入法名称省略显示，同时保留完整悬停提示和无障碍标签。
- 菜单展开时实时刷新顶部状态与操作提示，保留原生菜单操作和退出快捷键。
- 使用系统语义颜色适配深浅色外观，并新增菜单状态、长名称和原生操作回归检查。

## 下载与兼容性

- 推荐下载 `universal`，同时支持 Apple Silicon 和 Intel Mac；另提供 `arm64` 和 `x86_64`。
- 最低系统要求保持 macOS 12；登录启动功能需要 macOS 13 或更高版本。
- 安装前请退出旧版，再将新版拖入“应用程序”替换。
- 安装包使用本地 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
