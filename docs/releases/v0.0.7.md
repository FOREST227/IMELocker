# 输入法锁定 v0.0.7

## 新增功能与体验优化

- **按应用暂停锁定**：支持在菜单中将当前前台应用（如终端、代码编辑器等）加入例外列表，切入时自动暂停锁定，切回其他应用后自动恢复；支持在「例外应用」子菜单中移除单项或清空全部。
- **菜单栏图标快捷切换**：左键点击照常打开菜单，**右键 / Option+左键 / Control+左键**菜单栏图标可直接快速切换锁定或解锁。
- **更直观的状态图标**：区分已锁定（实心盾牌锁）、已解锁（开锁图标）、安全输入/应用例外暂停（暂停圆圈）、未选/目标不可用（感叹号盾牌）与恢复中状态，并统一菜单顶部图标尺寸与「当前：」文案排版。

## 稳定性与性能优化

- **修复解锁后状态显示**：解除锁定后，菜单列表中的输入法项不再残留已选实心圆点。
- **降低闲置能耗**：已锁定且状态未变化时，5 秒兜底检查不再重复刷新输入法列表、查询登录项状态或触发冗余界面重绘；打开菜单时主动刷新输入法列表。
- **唤醒与解锁即时恢复**：新增系统休眠唤醒、屏幕唤醒与锁屏解锁监听，恢复目标输入法无需等待轮询。
- **异常切回退避保护**：连续切换失败或被其他应用高频弹回时自动启用指数退避（最高 2 秒），避免争抢 CPU。
- **单实例保护与正式 Bundle ID**：阻止重复启动多个菜单栏实例（重启操作正常放行）；Bundle ID 正式定型为 `com.forest227.IMELocker`，首次升级时自动迁移旧版锁定配置。
- **更新检查优化**：检查更新请求超时放宽至 8 秒，补充 `User-Agent` 请求头并修复弹窗按钮宽度重排。

## 下载与兼容性

- 推荐下载 `universal`，同时支持 Apple Silicon 和 Intel Mac；另提供 `arm64` 和 `x86_64`。
- 发布页同步附带 `SHA256SUMS.txt`，可用于校验 `.dmg` 文件完整性。
- 最低系统要求保持 macOS 12；登录启动功能需要 macOS 13 或更高版本。
- 安装前请退出旧版，再将新版拖入“应用程序”替换；因本版正式启用新的 Bundle ID，如此前开启过「登录时启动」，升级后建议重新确认一次登录项设置。
- 安装包使用本地 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
