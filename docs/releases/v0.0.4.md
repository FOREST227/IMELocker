# 输入法锁定 v0.0.4

## 修复

- 修正输入法变化通知的监听方式，恢复即时锁定与输入法列表刷新。
- 准确显示未选择目标、目标不可用、安全输入暂停、恢复中及已锁定状态。
- 关于窗口异步检查更新，避免网络请求阻塞界面和输入法恢复；只有远端版本更高时才提示更新。
- 重启应用时，确认新实例成功启动后再退出当前实例。

## 优化

- 更新检查结果缓存 15 分钟，并合并同时发起的请求。
- 输入法列表周期刷新，补偿遗漏的系统通知；状态图标仅在状态变化时重绘。
- 构建严格校验版本、实际架构和签名；universal 构建缺少任一架构即失败。
- 发布流程复用架构编译产物，上传成功后才公开新版本，并保护已发布的安装包。
- 新增锁定、通知、安全输入恢复、更新检查、构建和发布回归测试。

## 下载与兼容性

- `universal`：同时支持 Apple Silicon 和 Intel Mac。
- `arm64`：仅适用于 Apple Silicon。
- `x86_64`：适用于 Intel Mac。
- 最低系统要求为 macOS 12；登录启动功能需要 macOS 13 或更高版本。
- 安装包使用本地 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
